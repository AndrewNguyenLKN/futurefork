# Run artifacts

FutureFork writes reproducible experiment results to `artifacts/runs/<run-id>/`.

Artifact bundles are generated by the runner and must not be hand-edited. If a run must be annotated, add a separate `human-notes.md` file and record its author/time without changing original logs or manifests.

Large transient worktrees and dependency caches do not belong here. Public demo artifacts should contain only synthetic data and allowlisted environment metadata.
